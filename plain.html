How to read this

Every slice and bundle opens with a briefing: the landmark papers (journal tier × topical fit, all years), then the latest 120 days, then reviews. Each line carries the paper's own key claim. Below each briefing are links to the complete ranked list (one line per paper) and to full abstracts. Slice codes in brackets show where else a paper belongs; a star marks its primary slice.

To catch up, start with the latest papers. For a proposal, start with its bundle.
